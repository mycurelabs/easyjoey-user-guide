# Find or add a patient

Look up a patient who's been to your clinic before, or add a new one.
{ .meta }

**Time:** about 3 minutes · **You'll need:** the patient's name, sex and date of birth.
{ .meta }

## Before you start

- [Sign in](../getting-started/sign-in-and-home.md) to EasyJoey.
- Always search first. Adding someone who is already on file creates a second, separate record.

## Steps

### 1. Open Patients

Tap **Patients** in the sidebar.

You should see: your patients as folders, sorted by last name (**Sort: Name A–Z**).
Each folder shows the patient's name, sex, age and number of encounters.
{ .see }

![The Patients page in Grid view, with the Name or patient number search box, Sort, View and the + button above the patient folders](../assets/find-or-add-a-patient/01-patients.webp)

!!! tip "Prefer a list?"
    Use **View** to switch between **Grid**, **List** and **Table**. The table shows the most at once: **Patient**, **Sex**, **Age**, **Encounters**, **Date registered**, **Last visit** and **Status**.

### 2. Search for the patient

Type part of the name, or the patient number, in **Name or patient number**. The list updates as you type.

You should see: only the patients that match. Tap a folder to open that patient.
Tap the clear button at the right end of the search box to clear it.
{ .see }

![The Patients page after searching for Reyes: the matching patient folders, each with Reyes as a middle name](../assets/find-or-add-a-patient/02-search.webp)

!!! note
    Search matches first, middle and last names. Searching *Reyes* also finds patients whose middle name is Reyes.

If the patient isn't there, add them in the next step.

### 3. Open the Add patient form

Tap the **+** button next to **View**. On a wide screen the button reads **Add patient**.

You should see: **Add patient**, open on **Identity**. The footer says how many required fields are left, for example **4 required fields still need attention**. **Add patient** stays greyed out until they're filled.
{ .see }

![The empty Add patient form on Identity, with Required next to Identity and "4 required fields still need attention" in the footer](../assets/find-or-add-a-patient/03-add-patient-empty.webp)

### 4. Fill in the required fields

On **Identity**, fill in the four fields marked with a red star:

1. **First name**
2. **Last name**
3. **Sex**: tap **Select sex** and choose.
4. **Date of birth**: tap the box and pick the date.

If the patient genuinely can't give their birthday, tick **Date of birth is unknown** instead. Never type a made-up date.

You should see: **Required information complete** in the footer, and **Add patient** turns dark.
{ .see }

![Identity filled in for a new patient: first and last name, Sex set to Female, and a date of birth, with Required information complete in the footer](../assets/find-or-add-a-patient/04-add-patient-filled.webp)

### 5. Add contact details and anything else you have

The form shows one section at a time. Tap a section in the list on the left to open it. Nothing here is required, but it saves time later:

- **Contact**: **Mobile number**, **Email**, **Home phone**.
- **Demographics**, **Address**, **Family & Emergency**.
- **Insurance & Benefits**: HMO cards, and Senior Citizen or PWD IDs.
- **Allergies**, **Vaccinations** and **Medical history**: record these before the first consultation.

You should see: the section you tapped, with your details filled in.
{ .see }

![The Contact section of Add patient with a mobile number filled in](../assets/find-or-add-a-patient/05-add-patient-contact.webp)

### 6. Save

Tap **Add patient**.

You should see: a **Patient added** message, and the new patient's page opens on **Encounters**.
{ .see }

![The new patient's page on the Encounters tab, showing No encounters yet and a Start encounter button](../assets/start-an-encounter/01-no-encounters.webp)

## Tips

!!! tip "Search from anywhere"
    The **Search…** box at the top of the sidebar also finds patients. Type a name and press Enter.

!!! warning "If something goes wrong"
    **Add patient is greyed out.** A required field is still empty. The footer says how many, and **Required** appears next to **Identity**.

    **You closed the form by mistake.** If you had typed something, EasyJoey asks **Discard this patient?**. Tap **Keep editing** to go back to your work.

!!! info "Good to know"
    The patient's details can be changed at any time. See [The patient page and profile](patient-page-and-profile.md).
